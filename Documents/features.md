# Features

This document lists the key features of the Giovanni Carlo Volpe Portfolio website, based on the current implementation.

## Core Features
- **Hero Section**: Displays cover image, profile picture, name, and title with absolute positioning.
- **Navigation Menu**: Links to sections with smooth scrolling via JavaScript.
- **Contacts Section**: Lists email, phone, location, LinkedIn, and languages with clickable links.
- **Skills Section**: Details software proficiencies categorized by level.
- **Education Section**: Highlights degrees, internships, and visiting studies.
- **Work Experience Section**: Describes professional roles and projects.
- **Projects Section**: Grid of project cards with images, titles, descriptions, and placeholder links.
- **Footer**: Copyright notice.

## Styling Features (CSS)
- Responsive layout using Flexbox and Grid.
- Custom fonts (Roboto) via Google Fonts.
- Hover effects: Underline on links, scale on project cards.
- Media queries for mobile optimization (e.g., stacked layouts below 768px).
- Borders and padding for structured sections.
- Background images and object-fit for profile and project images.

## Interactivity Features (JavaScript)
- Smooth scroll for navigation links using `scrollIntoView`.
- Event listeners for project links with alert placeholders.
- DOMContentLoaded for safe script execution.
- Console logging for load confirmation.

## Additional Features
- Semantic HTML for better accessibility.
- External links for contact and social profiles.
- Placeholder functionality for expandable project details.
- Mobile-first responsive design.
