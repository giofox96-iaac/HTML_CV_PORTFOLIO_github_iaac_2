# Giovanni Carlo Volpe Portfolio

A personal portfolio website for Giovanni Carlo Volpe, showcasing his work as an Architect and Computational Designer.

## Description
This static website presents Giovanni's professional background, including his education, skills, work experience, and selected projects. It features a responsive design with a hero section, navigation, and a grid layout for projects. Built with HTML5, CSS3, and JavaScript for a clean, interactive experience.

## Features
- Responsive design for mobile and desktop.
- Smooth scrolling navigation.
- Hover effects on project cards and links.
- Sections for contacts, skills, education, work, and projects.
- Image galleries for projects with placeholder links.

## Installation
1. Clone the repository: `git clone https://github.com/username/portfolio.git`
2. Ensure images are in the `Pictures/` directory.
3. Open `index.html` in a web browser.

## Usage
- Navigate using the menu to jump to sections with smooth scrolling.
- Hover over project cards for scaling effects.
- Click on project links for details (currently placeholders with alerts).
- View on any device; optimized for modern browsers.

## Technologies Used
- HTML5 for structure.
- CSS3 with Flexbox, Grid, and media queries for responsive layout.
- JavaScript for smooth scrolling and event handling.

## File Structure
- `index.html`: Main HTML file.
- `style.css`: Stylesheet.
- `script.js`: JavaScript for interactivity.
- `Pictures/`: Image assets.
- `Documents/`: Documentation files.
