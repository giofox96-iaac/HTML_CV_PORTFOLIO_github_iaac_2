# Prompt

This document outlines the history of prompts used during the development of the Giovanni Carlo Volpe Portfolio project.

## Initial Prompt (v1.0)
Create a personal portfolio website for Giovanni Carlo Volpe, an Architect and Computational Designer. The site should showcase his education, work experience, skills, and best projects in a clean, professional layout.

### Requirements
- Responsive HTML structure with semantic elements.
- Sections for contacts, skills, education, work, and projects.
- Integration of images and links.
- Basic styling via CSS (linked as style.css).
- Simple JavaScript for interactivity (linked as script.js).
- Use of a navigation menu for easy access to sections.

### Key Features
- Hero section with profile picture and name.
- Left sidebar for contacts and skills.
- Right section for education and work.
- Projects grid with images and descriptions.
- Footer with copyright.

### Technologies
- HTML5
- CSS3
- JavaScript (ES6+)
